Postback macros, side by side

Macros, signature methods and reversal rules for tracking platforms and offerwall networks. Every fact links to the vendor page it comes from. Compare them at a glance, search the sheet or build an example postback URL.

    Use it in your project Read the guide

    What it is for

    Three jobs it does for a rewards app, site, game or community that credits users from postbacks.

    • Wire an offerwall postback

      Look up the macros a network sends, such as the user ID, reward and transaction ID, and build the postback URL to paste into its dashboard.

    • Verify every reward

      See how each network signs its postbacks: the scheme, the signed input, the key and where the signature is sent, so only genuine requests credit a user.

    • Handle reversals and retries

      Check how a reversal arrives and what your endpoint has to answer, so a chargeback takes a reward back once and a retry never credits it twice.

        payout.mjs: the payout macro in a tracker's outbound postback
        
          
        import { readFileSync } from 'node:fs';

const data = JSON.parse(readFileSync('macros.json', 'utf8'));
const voluum = data.tracking_platforms.find((p) => p.id === 'voluum');
const payout = voluum.macros.find((m) => m.direction === 'outbound' && m.concept === 'amount');
console.log(payout.macro, payout.source);
